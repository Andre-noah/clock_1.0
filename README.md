# Flip Clock — ретро-часы с перекидными цифрами

Простой чёрно-белый скринсейвер для смартфона в виде PWA (можно установить на домашний экран и открывать как отдельное приложение).

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `flip-clock`).
2. Загрузите в него все файлы из этого архива (сохранив структуру папок, включая `icons/`).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main`, папку `/ (root)`.
5. Сохраните — через минуту-другую сайт появится по адресу вида:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Установка на телефон как приложение

- **Android (Chrome):** откройте ссылку → меню (⋮) → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari):** откройте ссылку → кнопка «Поделиться» → «На экран «Домой»».

После установки часы будут открываться в полноэкранном режиме без адресной строки, как отдельный скринсейвер.

## Что внутри

- `index.html` — разметка и стили (чёрный фон, белые цифры, эффект переворота).
- `script.js` — логика часов и анимация переворота цифр.
- `manifest.json` — манифест PWA (имя, иконки, полноэкранный режим).
- `service-worker.js` — офлайн-кэш, чтобы часы открывались и без сети.
- `icons/` — иконки приложения разных размеров.

## Настройка

- Цвета заданы CSS-переменными в начале `index.html` (`--bg`, `--fg`, `--dim`, `--card`) — можно поменять оттенки, не трогая остальной код.
- Скорость анимации переворота — переменная `FLIP_MS` в начале `script.js` (сейчас 300 мс на каждую половину).
- Нажатие на экран скрывает/показывает подпись с секундами внизу.
- Экран старается не гаснуть (Wake Lock API) — поддерживается в Chrome/Edge на Android; в Safari на iOS эта функция браузером пока не поддерживается, так что для постоянного «неспящего» экрана там лучше использовать системный скринсейвер/настройки автоблокировки.
